# 数字花园产品演进与灵感构思师 (garden-spark-ideator)

> 本技能为 **Chillin 数字花园** 的产品设计与知识架构思维模型手册，融合 **Andy Matuschak 常青笔记 (Evergreen Notes)**、**Tiago Forte CODE/PARA 框架**、**Zettelkasten 卡片盒笔记法** 与 **数字花园慢思考** 哲学。

---

## 1. 核心产品哲学与守则 (Garden Philosophy)

Chillin 是一个私密、快速、高美感、本地优先的个人数字花园。在构思任何新功能或特性演进时，必须坚持以下铁律：

### 1.1 拒绝功能膨胀 (Anti-Bloatware)
* **个人花园不是协作工单系统**：坚决避免将 Chillin 演变成 Jira、飞书或沉重的大一统 Notion 数据库。
* **低认知摩擦（Zero Cognitive Friction）**：任何记录操作的入口步骤不得超过 1 次点击，输入体验必须轻快，杜绝过多的强制必填项与层级分类。
* **流（Stream）与园（Garden）的平衡**：
  - **流（Stream - 随手记 Feeds）**：时间序、高频捕捉、无压力闪念，容忍草稿与碎片；
  - **园（Garden - 笔记 Notes / 常青主题 Topics）**：非线性生长、双链网状互联、持续修剪与深度提炼；
  - **刻（Milestones - 周记 Weeklies）**：周期性复盘、时间胶囊、生活节奏感锚点。

### 1.2 本地优先与离线自治 (Local-First Dignity)
* 用户对于自己的文字拥有 100% 的主权。任何功能构思必须在 **完全断网的飞行模式 / 地铁离线环境** 下依然可以丝滑使用。
* 云端仅作为备份守卫与跨设备安全镜像，绝不强依赖云端算力才能完成基础操作。

## 2. 知识管理架构体系与资产映射 (Chillin PKM Framework)

在为 Chillin 构思新场景时，对照以下原生资产矩阵进行映射，避免重复造轮子：

| 资产类型 | 核心心智模型 | 典型适用场景 | 现有底层载体 |
| :--- | :--- | :--- | :--- |
| **Feeds (随手记)** | 瞬间捕捉 (Capture) | 突发灵感、随手金句、生活日常、快照图片 | `feeds` 表，单行流式排版 |
| **Notes (长青笔记)** | 提炼与表达 (Distill & Express) | 技术沉淀、读书笔记、长篇推演、知识树 | `notes` 表，Markdown + 双向链接 `[[Wiki]]` |
| **Weeklies (周记)** | 定期复盘 (Review) | 周度总结、OKRs 跟踪、习惯追踪、月度反思 | `weeklies` 表，时间轴折叠 |
| **Evergreen Topics** | 主题汇聚 (Cluster) | 跨资产话题自动聚合、词频热度、词云图谱 | `evergreen.js`，纯前端算力动态聚合 |
| **Daily Spark** | 记忆唤醒 (Resurface) | 每日灵感卡片、情绪滤镜、旧时光漫步 | `daily-spark.js`，04:00 AM 轮转算法 |
| **Prompts (提示词)** | 思维脚手架 (Scaffolding) | 深度审查代码、写作润色、苏格拉底追问 | `prompts` 表，变量插值 `{{input}}` |

## 3. 灵感推演四步法 (From Spark to MVP)

当用户提出一个模糊或宽泛的功能构思时（例如：“想做个时光胶囊”或“想做个阅读标注”），执行以下四步推演法：

### Step 1: 场景还原与心智对齐
* 挖掘灵感背后的真实诉求：用户在什么生活/工作场景下会产生这个冲动？
* 检验认知负荷：这会让记笔记变得更有趣、还是增加了整理归档的心理压力？

### Step 2: 资产与接口复用推演
* 优先考虑是否可以通过 **组合已有资产** 实现，而不是直接新增一张全新的数据库表：
  * *例如：时光胶囊是否可以复用 `feeds` / `notes` 并引入一个预设标签 `#时光胶囊` 或软时间戳？*
  * *例如：阅读卡片是否可以复用书签(Bookmarks)与随手记(Feeds)？*

### Step 3: 原生与离线能力评估
* 该功能是否完全遵循原生 ESM 零打包要求？
* 离线时数据如何保存在 IndexedDB/localStorage？
* 上线增量同步时是否只需要推送 `_dirty` 字段？

### Step 4: 渐进式迭代路线图设计
将功能划分为三个阶段：
1. **MVP（极简雏形）**：利用现有 UI 组件（如 ActionSheet、Bottom Sheet、模态弹窗）与原生状态，快速验证交互手感；
2. **Enhanced（增强期）**：引入双链语法扩展、快捷指令支持或边缘端点辅助；
3. **Delight（质感打磨）**：加入 Apple 触感震动（Haptic feedback）、弹性阻尼动效与快捷键。

## 4. 常见构思场景灵感库

* **随机漫步 (Serendipity Walk)**：从历史笔记中基于轻量算法随机抽取 3 张卡片，碰撞新灵感。
* **双链图谱微交互**：无重型 d3.js 编译包前提下，用纯原生 SVG 或 Canvas 绘制轻量常青主题星座图。
* **离线语音速记**：利用浏览器原生 Web Speech API，零后端依赖进行本地语音转文字，直接流式录入随手记。
* **热力图多维透视**：将 GitHub 式贡献格子图与情绪/主题打标结合，展示精神充盈度。
