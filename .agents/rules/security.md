# 数据安全与防御式编程规范 (Security Rule)

> 本规范约束 Chillin 项目在数据加密、身份鉴权、文件上传、网络请求及富文本渲染层面的安全防线。

---

## 1. 身份认证与密码加密防线

1. **PBKDF2 强哈希算法**：
   * 用户密码必须使用标准 PBKDF2（100,000 次迭代，SHA-256 算法，配合 16 字节独立随机 Salt）；这是 Cloudflare Workers WebCrypto 的硬上限，严禁写成 600,000（边缘会抛 NotSupportedError，登录/注册直接 500）；
   * 旧迭代次数的历史哈希不得强制失效：登录校验成功后须就地重哈希升级到当前迭代数；
   * 严禁明文存储密码，严禁使用 MD5、SHA-1 或单次 SHA-256 等不安全哈希。
2. **时序安全比对 (Timing-Safe Compare)**：
   * Session Token、认证密钥或哈希值的比较必须调用 `timingSafeEqualStr` 进行恒定时间逐字节异或比对；
   * **绝对严禁直接使用 JavaScript 的 `===` 运算符进行密码或 Token 比对**，彻底杜绝基于时序分析的侧信道攻击 (Side-Channel Timing Attack)。

---

## 2. 文件上传与二进制魔数防线

1. **二进制魔数严格嗅探 (Magic-Byte Sniffing)**：
   * 接受任何客户端上传的图片附件前，后端必须在内存中读取前几个字节的二进制魔数：
     * **PNG**: `89 50 4E 47 0D 0A 1A 0A`
     * **JPEG**: `FF D8 FF`
     * **GIF**: `47 49 46 38`
     * **WebP**: `52 49 46 46` ... `57 45 42 50`
   * 坚决拦截利用文件后缀名欺骗上传可执行脚本、SVG 跨站脚本或 Polyglot 恶意载荷的行为。

---

## 3. 服务端出站抓取 (SSRF) 防御 —— 白名单制

服务端出站抓取点仅收敛于外链速览（[`workers/src/bot-links.js`](../../workers/src/bot-links.js)），严格实行白名单与防御式网络约束：

1. **域名白名单**：只允许 `xiaoyuzhoufm.com`（页面）与 `xyzcdn.net`（图床）及其子域；**不做通用外链预览**，白名单之外的 URL 绝不出站请求。
2. **协议与端口**：只允许 `https:`，端口必须是 443（显式非默认端口一律拒绝）；拒绝包含 userinfo 的 URL。
3. **主机形态与私网阻断**：严格拒绝 IP 字面量（含 IPv4/IPv6）、`localhost` / `*.local` 与私网/链路本地/云元数据网段（10.x / 127.x / 169.254.x / 172.16-31.x / 192.168.x）；FQDN 尾点先归一化再比对后缀。
4. **重定向逐跳复核**：必须使用 `redirect: 'manual'` 手动跟随，每一跳重定向目标都重新过白名单校验（最多 3 跳），严禁交给 fetch 自动跟随。
5. **超时与体积封顶**：设置 `AbortSignal.timeout(6000)`；HTML ≤ 512KB、封面 ≤ 4MB，读取时按上限截断并 `cancel()`，严禁无界读入内存。
6. **优雅降级**：网络异常或抓取失败时如实告知用户，提供「记录：<链接>」的文本兜底，抓取不到的内容绝不入库。
7. **可选代理代读**：直连被目标出口封禁（如 HTTP 403）时，若环境变量配置了 `LINK_READER_API_KEY`，才允许将白名单内的目标 URL 交给第三方读取服务（默认 `https://r.jina.ai`，可用 `LINK_READER_URL` 覆盖，且仅接受 https、拒绝 userinfo）；密钥严禁入库或输出至日志；未配置密钥时该路径完全关闭。代读返回的封面图片仍须严格过图床白名单，严禁热链第三方图片。请求声明 `Accept: text/html`；若响应仍为 JSON，优先解析内嵌 HTML 内容，字段仅作无封面时的元数据回落。

---

## 4. 前端防存储型 XSS (DOMPurify 过滤)

1. **富文本注入白名单**：
   * 任何来自用户输入、外链提取或数据库持久化文本在通过 `innerHTML` 渲染前，必须经过 `DOMPurify.sanitize()` 进行白名单过滤清洗；
   * 严格避免用户或第三方注入 `<script>`、`onload`、`javascript:` 等恶意代码。
